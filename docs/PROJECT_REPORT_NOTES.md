# Project Report Notes

## Project Title

CodeArena - Hackathon Management Platform

## Problem Statement

College hackathons are often managed through Google Forms, WhatsApp, email, spreadsheets, and shared drives. This causes confusion around registrations, team approvals, judging, submissions, and result declaration. CodeArena centralizes these workflows in one MERN application.

## Objectives

- Allow organizers to create and manage hackathons.
- Allow participants to register, form teams, and submit projects.
- Allow judges to review assigned submissions with structured criteria.
- Allow admins to oversee platform activity.
- Provide dashboards, search, filters, and leaderboard results.

## Modules Implemented

- Authentication and authorization
- Role-based access control
- Hackathon CRUD
- Registration approval workflow
- Team management
- Project submissions
- Judge evaluations
- Leaderboard and result publishing
- Role-based dashboard summaries
- Responsive frontend pages
